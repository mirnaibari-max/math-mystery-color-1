# Math Mystery Color Challenge (GitHub Pages)

This is a static website. It does not need Hatchable or a paid hosting plan.

## Files
- `index.html` — game page
- `styles.css` — design and responsive layout
- `app.js` — grade questions, answer checking, unlockable colors, and click-to-fill coloring
- `assets/grade7.png`, `assets/grade8.png`, `assets/grade9.png` — the original worksheet pictures from the supplied Word document

## Publish for free with GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com.
2. Click **New repository**. Name it `math-mystery-color`. Choose **Public** and create it.
3. On the repository page, click **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, `app.js`, and the `assets` folder (with all three PNG files). Keep the folder structure exactly as shown.
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes. GitHub will show your website link in Settings → Pages. It usually looks like `https://YOUR-USERNAME.github.io/math-mystery-color/`.
10. Open that link and test Grade 7, 8, and 9, then share it with students.

## Important notes
- GitHub Pages is free for public repositories. Do not put student personal information in the repository.
- The current app runs entirely in the student's browser. It does not send names or scores to a teacher dashboard.
- Students can solve questions to unlock colors. The worksheet picture is colored by clicking a white region away from printed lines. Because the source pictures are line art with many small regions, some areas may need a second click closer to the center.
- Some worksheet questions have answers not represented in the printed color key; the app gives those questions an extra color so the activity can still be completed. Review the questions and color key before using it for assessment.
